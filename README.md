# anomaly-agent

A lightweight, zero-trust anomaly detection engine for distributed systems.

## What it does

Learns the normal behavior of a system (CPU, memory, disk, network) and alerts
on deviations before they cause an outage.

## Status

Early development. Collector implemented.

## Structure

- `src/` — core logic
- `tests/` — test suite
- `requirements.txt` — dependencies
